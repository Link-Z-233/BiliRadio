## Overview

两部分：**A. 订阅源（`SourcePage`）多选交互重构**，对齐鸿蒙文件管理器范式——长按剧集行（预选）+ 顶栏 ··· 旁常驻图标按钮双入口（页头按钮移除，根因：页头随列表滚动离屏「一滑就没了」）；多选态顶栏「取消（替换返回位）+ 已选 N 项」（···/刷新/退订不可达）；行首勾选框进入时淡入 + 行内容右移让位；底部操作位——左下角「标记已看完」（批量写本地播放历史 progress=-1，带二次确认，仅本地标记不向 B 站云端上报完播心跳，多P 视频按 bvid 级标记，仅订阅源多选有此按钮）+ 右下角「加入队列 (N)」（N=0 禁用）；进入/退出多选全链路过渡动画，方向互逆。入队语义不变（空队列起播/非空追加不打断/去重/toast 反馈/完成后退出多选）。**B. 播放队列（`QueueSheet`）与播放历史（`HistorySheet`）多选进出动画补齐**——与订阅源同款过渡动画（勾选框淡入淡出/行内容位移/头部切换），既有交互语义零变化。`v0.5-part2` 交付的多选功能（全选/底部操作条/页头入口）由本 spec US1 取代其交互设计，US2 取代其动画空白。

**追加2 概述**：二轮目检五项改进——①勾选框与封面间距对称化（现「紧贴封面、两侧空白不一致」，共享 `SelectCheckbox` 层修复，三处多选一致）；②多选「复选框区拖选」取代「选择至此」（多选态按在行首勾选框列上下拖，方向性扫选与鸿蒙文件管理器一致——起点未选=加扫全选、起点已选=减扫全取消，加的时候只加、减的时候只减；铺满订阅源/队列/历史三处多选场景；拖到列表可视区边缘自动滚动继续拖选、到尽头停止；区间选择状态机与按钮整体移除，既有其余选中方式全部保留）；③MiniPlayer 悬浮化——首页订阅列表与订阅源详情剧集列表去除底部空白预留，内容滚动时从胶囊下方穿过（毛玻璃透出），滚到底时最后一条完整露出在胶囊上方不被遮挡（设置页维持现状）；④订阅源多选底部操作由整条卡片拆为两枚独立悬浮按钮（左下「标记已看完」、右下「加入队列 (N)」，避让 MiniPlayer 与导航区语义保留）；⑤`CoverThumb` 封面图禁用系统拖拽（根因：Image 默认 draggable，长按拖动唤起中转站/分享；共享组件层修复，全应用生效）。播放出错提醒（目检第 5 条）用户明确延后 part3，本轮不实施。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 订阅源多选交互重构 (Priority: P1)

重构 `v0.5-part2` US2 交付的订阅源多选交互，对齐鸿蒙文件管理器范式，取代其入口/操作条/全选设计（入队语义保留）：

- **入口**：长按剧集行进入多选并预选该行；顶栏 ··· 旁常驻多选图标按钮；多选不进 ··· 菜单；页头多选按钮移除（根因：页头随列表滚动离屏，「一滑就没了」；顶栏常驻不随滚动离屏）
- **多选态顶栏**：左「取消」（替换返回位）、中「已选 N 项」、右留空（···/多选按钮隐藏，刷新/退订不可达）；系统返回等同「取消」
- **行内**：行首勾选框，进入时淡入 + 行内容右移让位，退出反向
- **底部**：左下角「标记已看完」按钮（N=0 禁用）——点弹二次确认「确定标记 N 集为已看完吗？」，确认后批量把选中剧集写入本地播放历史（progress=-1，bvid 级，仅本地不向 B 站云端上报），行上立即显示已播标记，toast 反馈后退出多选；右下角「加入队列 (N)」浮动按钮（N=0 禁用，避让 MiniPlayer 与导航区）
- **动画**：进入/退出多选全链路过渡（勾选框淡入/行内容位移、顶栏切换、底部按钮滑入滑出），方向互逆
- 全选/取消全选移除；入队语义不变（复用现有批量入队、toast 反馈、完成后退出多选）
- ~~底部中间「选择至此」~~（追加2 取代：FR-003 被 FR-014 取代，「选择至此」按钮与区间选择状态机移除，快速多选改走复选框区拖选，见 US4）

**Why this priority**: 交互重构是本轮核心；在 `v0.5-part2` 剧集行等高（US7/FR-014）基础上改行内布局，是 US2 动画的载体。

**Independent Test**: 长按与顶栏按钮双入口进入多选；「加入队列 (N)」核对队列内容与 toast；进出多选观察全链路动画与反向性。

**Acceptance Scenarios**:

1. **Given** 任意剧集行，**When** 长按，**Then** 进入多选且该行预选中，勾选框淡入/行内容右移有过渡
2. **Given** 常规态顶栏，**When** 渲染，**Then** ··· 旁显示多选图标按钮（多选不进 ··· 菜单），页头无多选按钮
3. **Given** 多选态，**When** 顶栏渲染，**Then** 左「取消」、中「已选 N 项」、右侧无全选；系统返回等同取消
4. ~~**Given** 已勾选一条作锚点，**When** 点「选择至此」再点另一行，**Then** 锚点→该行之间全部剧集选中~~（追加2 取代于 FR-014）
5. ~~**Given** 区间选择态，**When** 再次点「选择至此」，**Then** 退出区间选择态，已选集不变~~（追加2 取代于 FR-014）
6. **Given** 无选中（N=0），**When** 底部渲染，**Then** 「标记已看完」与「加入队列 (0)」均禁用
7. **Given** 已选 N 集，**When** 点「加入队列 (N)」，**Then** 入队语义与现状一致（空队列起播/非空追加不打断/去重），toast 反馈后退出多选
8. **Given** 多选态，**When** 退出（取消/系统返回/入队完成），**Then** 勾选框淡出/行内容回位/底部按钮滑出，与进入互逆

12. **Given** 已播剧集再次被标记，**When** 确认标记，**Then** 幂等无副作用（不重复建历史条目）

### User Story 2 - 队列/历史多选进出动画 (Priority: P2)

播放队列（QueueSheet）与播放历史（HistorySheet）的多选进入/退出补齐与订阅源同款的过渡动画：行首勾选框淡入/淡出 + 行内容右移让位/回位、头部多选操作行与常规头部切换过渡；既有交互语义全部不变（长按进入、全选/移除/删除、面板关闭自动退多选、多选态不挂左滑删除）。

**Why this priority**: 动画一致性补齐，不动布局结构与交互语义，在 US1 动画模式定型后叠加。

**Independent Test**: 队列/历史面板分别以头部按钮与长按进入多选再退出，观察勾选框与行内容过渡、头部切换过渡、退出反向性。

**Acceptance Scenarios**:

1. **Given** 播放队列面板，**When** 进入多选（头部按钮/长按组条目/长按单条目），**Then** 勾选框淡入、行内容右移让位、头部多选操作行切换有过渡
2. **Given** 队列多选，**When** 退出，**Then** 动画反向（勾选框淡出、行内容回位、头部恢复）
3. **Given** 播放历史面板，**When** 进入/退出多选，**Then** 同队列两条
4. **Given** 多选进出动画播放中快速再次操作，**When** 动画被打断，**Then** 终态以 selectMode 状态为准，无中间态残留
5. **Given** 多选态下面板关闭（自动退多选）后再打开，**When** 渲染，**Then** 常规态无勾选框/多选残留

### User Story 3 - 真机目检修复 + 多选共享逻辑抽取 (Priority: P1)【追加】

首轮真机目检（US1/US2 交付部署后用户自查）反馈 5 项修复 + 多选代码统一为共享逻辑：

- **系统返回动画退选（队列/历史）**：系统返回退出队列/历史多选现由 BackHandler 直翻 `selectMode`，与按钮退出不一致无过渡；改为组件注册「动画退多选」句柄（对齐既有 closeHandle 注册模式），BackHandler 优先调句柄，无句柄回退直翻
- **队列长按松手取消预选（历史无此问题）**：队列行长按为 `GestureGroup(Sequence, 长按, Pan)`（拖选需要），不拖动直接松手时整组判定失败，ArkUI 回退派发 onClick 把刚预选的条目取消；历史为裸长按无回退。修复：三处长按统一「长按守卫」——长按触发置守卫，onClick 命中守卫即吞掉本次点击并复位，下次按下重置守卫；队列拖选的 Sequence 结构保持
- **层序（订阅源+队列多选同开）**：系统返回应先退最上层（队列 L5）多选，现先退了订阅源（L3）的多选——`SourcePage.onBackPressed` 先查自身 `selectMode` 后调 `dismissOverlaysForBack`，层序颠倒；改为先 `dismissOverlaysForBack()`，返回 false 再处理自身多选
- **标记已看完行上标记立即可见**：`markWatched` 异步落盘 vs `loadPlayedSet` 同步读文件竞态——读到旧文件无已播标记，退出重进才出现；`loadPlayedSet` 改读 `controller.playHistory`（内存真相源，markWatched 同步更新）
- **多选共享逻辑抽取**：`component/SelectCheckbox.ets` 共用组件（恒挂载容器宽度/opacity 动画 + Checkbox 统一样式，收敛三处多个挂载点）；`service/SelectLogic.ets` 纯静态助手（Set 引用替换 toggle）+ `LongPressGuard` 纯类；队列/历史选中集合数组→`Set<string>` 引用替换（对齐订阅源既有模式）；三处方法命名对齐（enter/exitSelectMode、toggleSelect、selectedKeys）。**保留的场景差异**（不合并）：状态载体（订阅源页内 `@Local` boolean vs 队列/历史 `BoolState` 跨组件共享——BackHandler/Index 读键需要）；订阅源区间选择（追加2 起由复选框区拖选取代）；队列拖选；数据层（队列 LazyForEach+多P 三行型 vs 历史 ForEach+bvid 聚合行）

**Why this priority**: 目检阻断项（松手取消预选/层序错乱）直接破坏核心交互；共享抽取降低三处后续维护发散。

**Independent Test**: 队列长按不拖动松手预选保持；队列/历史系统返回退多选有动画；订阅源+队列多选同开系统返回先退队列多选；标记已看完行上 ✓ 立即可见；三处多选进出动画/勾选框样式一致。

**Acceptance Scenarios**:

1. **Given** 队列任意行，**When** 长按进入多选后不拖动直接松手，**Then** 预选保持，不触发取消勾选
2. **Given** 队列长按后拖动（拖选），**When** 拖选完成，**Then** 拖选能力不回归，守卫不误吞后续操作
3. **Given** 队列/历史多选态，**When** 系统返回，**Then** 勾选框淡出/行内容回位/头部恢复（与按钮退出同款动画）
4. **Given** 订阅源多选 + 队列多选同开，**When** 系统返回，**Then** 先退队列多选（动画），再退订阅源多选，最后关队列面板/页面返回链逐层
5. **Given** 订阅源多选选 N 集，**When** 标记已看完确认，**Then** 行上已播标记立即显示（无需退出重进）
6. **Given** 三处多选，**When** 进出，**Then** 勾选框/动画/样式一致；命名与集合模式统一（Set 引用替换）
7. **Given** 队列/历史组件未注册句柄（异常时序），**When** 系统返回退多选，**Then** 回退直翻不崩溃

### User Story 4 - 二轮目检改进：间距对称 / 复选框区拖选 / MiniPlayer 悬浮化 / 独立悬浮操作按钮 / 封面禁拖拽 (Priority: P1)【追加2】

二轮真机目检五项改进（第 5 项「播放出错提醒」延后 part3，本轮不实施）：

- **勾选框间距对称化**：现多选态行首勾选框「紧贴封面、两侧空白不一致」（左缘↔勾选框与勾选框↔封面间距不等）；修复为两侧空白对称一致，在共享 `SelectCheckbox` 组件层修复，三处多选（订阅源/队列/历史）视觉一致
- **复选框区拖选（取代「选择至此」）**：多选模式下，手指按在行首勾选框列上下拖动，**方向性扫选（与鸿蒙文件管理器一致）**——拖选起点行未选中则本次拖动为**加扫**（滑过路径上的行全选中），起点行已选中则为**减扫**（滑过路径上的行全取消）；扫选模式于拖动开始时锁定（加的时候只加、减的时候只减，回扫不反向）；拖到列表可视区上下边缘时**列表自动滚动**，滚动显现的行继续扫选，滚到已加载尽头自动停止；「选择至此」按钮与区间选择状态机（rangeSelecting/anchorBvid）整体移除；既有选中方式全部保留（单行点击勾选/勾选框点击/队列长按+拖动拖选/历史点选+全选）；**三处多选场景统一**（订阅源剧集行/队列条目行/历史聚合行）
- **MiniPlayer 悬浮化**：首页订阅列表与订阅源详情剧集列表去除底部空白预留，列表内容滚动时从迷你播放胶囊**下方穿过**（毛玻璃透出滚动内容）；滚到底时**最后一条完整露出在胶囊上方不被遮挡**；设置页维持现状
- **独立悬浮操作按钮**：订阅源多选底部操作由整条卡片拆为两枚**独立悬浮胶囊**——左下「标记已看完」、右下「加入队列 (N)」（N=0 禁用），位置沿袭现三位置布局（中间位随「选择至此」移除而消失）；底部避让 MiniPlayer 与导航区语义保留
- **封面禁拖拽**：`CoverThumb` 封面图禁用系统拖拽——根因：鸿蒙 `Image` 默认 `draggable`，订阅源详情页头封面长按拖动唤起中转站/分享等系统功能；共享组件层修复，全应用所有封面生效

**Why this priority**: 五项均为目检直接反馈的体验缺陷；拖选取代「选择至此」是交互路径缩短（两次点击一段 → 一次拖动多段），间距/悬浮/按钮为视觉与操作舒适度收尾。

**Independent Test**: 进入多选观察勾选框两侧空白对称；三处（订阅源/队列/历史）勾选框列上下拖动滑过的行全选且已选行不受影响；拖到列表边缘自动滚动继续拖选、到尽头停止；首页/详情页列表滚动内容从胶囊下穿过、滚到底最后一条不被遮挡；多选底部两枚独立悬浮按钮位置与禁用态正确；订阅源详情页头封面长按拖动不再唤起中转站。

**Acceptance Scenarios**:

1. **Given** 任意一处多选态，**When** 观察行首勾选框，**Then** 勾选框与左侧留白、与右侧封面的间距对称一致，三处多选视觉一致
2. **Given** 任意一处多选态（订阅源/队列/历史），**When** 手指按在行首勾选框列（起点行未选中）向下/向上拖动，**Then** 滑过路径上的行依次全部选中（含起始行；队列分P 窄行按所属条目选中），模式锁定为加扫
3. **Given** 多选态拖选（起点行未选中），**When** 拖动路径经过已选行或回扫，**Then** 已选行保持选中（加扫不取消）
4. **Given** 任意一处多选态，**When** 手指按在已选中行的勾选框列拖动，**Then** 滑过路径上的行依次全部取消选中（含起始行），模式锁定为减扫；路径上未选中的行不受影响
5. **Given** 多选态，**When** 在勾选框列以外的行区域拖动，**Then** 行为为列表滚动（拖选不劫持常规滚动）
6. **Given** 订阅源多选态，**When** 渲染底部，**Then** 仅两枚独立悬浮按钮（左「标记已看完」/右「加入队列 (N)」），无整条操作卡、无「选择至此」
7. **Given** 首页/订阅源详情页，**When** 列表滚动，**Then** 内容从 MiniPlayer 下方穿过（毛玻璃透出）；滚到底最后一条完整露出在胶囊上方
8. **Given** 队列空态（占位条）/有内容态，**When** 两页列表滚动，**Then** 悬浮化行为一致，占位条同样透出滚动内容
9. **Given** 订阅源详情页头封面（及全应用任意封面），**When** 长按拖动，**Then** 不唤起中转站/分享等系统拖拽功能
10. **Given** 订阅源多选态，**When** 长按进入/顶栏进入/单行点击勾选/标记已看完/加入队列，**Then** 既有语义零回归（拖选为纯增量能力）
11. **Given** 拖选中手指持续按住并到达列表可视区上/下边缘，**When** 列表未到尽头，**Then** 列表自动滚动，滚动显现的行继续按锁定模式扫选；滚到已加载尽头自动停止，不崩溃不误选
12. **Given** 队列多选态，**When** 使用既有长按+拖动拖选，**Then** 既有拖选能力零回归（与勾选框列拖选并存互不干扰）
13. **Given** 历史/队列多选态，**When** 点选/全选/移除/删除，**Then** 既有能力零回归

### Edge Cases

- **多选与加载更早**：多选模式下触底加载更早仍可用，新载入剧集默认未选中
- **拖选与已加载边界**：复选框区拖选仅作用于已加载行；触底加载的 Loading 行不参与拖选；边缘自动滚动到已加载尽头即止
- **拖选与触底加载并存**：订阅源详情页拖选中边缘自动滚动触底照常触发加载更早；加载未完成期间拖选止于已加载行，新载入行默认未选中、可被继续拖选
- **队列分P 窄行拖选命中**：分P 窄行无行首勾选框，拖选滑过时按其所属条目（组）选中，不产生分P 级选中
- **两套拖选并存（队列）**：队列既有长按+拖动拖选（进多选后拖）与勾选框列拖选（多选态内拖）互不干扰，能力均可用
- **拖选与长按守卫并存**：长按进入多选（含预选）与复选框区拖选互不干扰；守卫残留由下次按下重置
- **拖选与勾选框点击并存**：点按单个勾选框切换勾选（既有）与拖选方向性扫选不冲突——拖选经过行的 Checkbox 若被直接点按仍走 onChange 切换语义
- **扫选模式锁定**：扫选模式由拖选起点行状态在按下时锁定——加扫中经过已选行保持选中、减扫中经过未选行保持未选中，同一拖动内无混合操作
- **动画中断终态**：进出多选动画播放中快速操作（连续进出/快速切行），终态以 selectMode 与选中集状态为准，无中间态残留
- **多选中 ··· 不可达**：多选态顶栏被替换，刷新/退订不可达，退出多选恢复
- **多选与空列表**：无剧集时顶栏多选按钮禁用或隐藏，长按无响应，不进入无意义的多选态
- **多选与 NEW/已播标记**：选中态与 NEW/已播标记并存时行布局稳定
- **多选中 MiniPlayer 避让**：右下角「加入队列 (N)」不遮挡 MiniPlayer，与导航区无重叠（悬浮化后避让以胶囊实际位置为准重算）
- **标记已看完与 NEW 徽标**：NEW 徽标基于发布时间，标记已看完不影响 NEW 显示（与已播标记正交）
- **标记已看完与历史容量**：批量写入沿用 HISTORY_MAX 截断与复合键去重（bvid:page），不重复建条目
- **标记已看完与当前播放**：标记当前正在播放的剧集仅写历史，不影响播放（不清队列、不打断）
- **长按守卫与拖选并存**：队列长按后拖动（拖选路径）不触发守卫误吞；守卫残留由下次按下重置，不影响后续点击
- **动画退选句柄缺失回退**：队列/历史组件未注册句柄时系统返回回退直翻退多选，不崩溃
- **多层多选同开层序**：订阅源多选 + 队列/历史多选同开时，系统返回自上而下逐层退出（队列多选→队列面板→…→订阅源多选→页面返回）
- **MiniPlayer 悬浮与多选底部按钮避让**：多选悬浮按钮与 MiniPlayer 不重叠（按钮 bottom 避让胶囊 + 导航区）
- **MiniPlayer 悬浮与触底加载**：滚到底触发加载更早时最后一条仍完整可见（加载指示/末尾提示不被胶囊遮挡）
- **封面禁拖拽与图片长按菜单**：禁拖拽不影响封面点击/长按既有交互（订阅源行长按进多选等）；仅去除系统拖拽/中转站唤起

## Assumptions

- 「鸿蒙文件管理器范式」指交互模式参考（长按进入多选、上下文顶栏、悬浮操作），非像素级复刻
- 拖选仅作用于已加载行；边缘自动滚动的触发区与速度档位按平台惯例（设计阶段定），一次连续拖选可跨滚动完成大范围选择
- 复选框区拖选的触区为勾选框列容器（含其左右留白），不扩展到整行——行其余区域拖动仍是列表滚动
- 方向性扫选：起点行未选中=加扫全选、起点行已选中=减扫全取消（与鸿蒙文件管理器一致，用户已确认语义）；单行点击/点勾选框切换仍可用于精确调整
