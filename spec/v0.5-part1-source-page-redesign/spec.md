# Feature Specification: 订阅详情页重写（B 站风格剧集行）

**Created**: 2026-10-13  
**Status**: Draft  
**Input**: User description: "把订阅详情页重写一遍吧，把封面带上"（重排参照 B 站客户端横版列表行；时长角标贴封面右下角；视觉重排、功能全保留）

## Overview

订阅详情页（`SourcePage`）剧集列表参照 B 站客户端横版列表行样式重排：每行左侧新增 16:9 封面缩略图，时长以半透明角标叠于封面右下角，右侧文字区收敛为「标题（≤2 行）+ 日期 + NEW/已播标记」。纯视觉重排——NEW 徽标、已播标记、播放全部、刷新、触底加载更早、退订等全部功能语义不变；页面头部（56vp 封面信息行）维持现状。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 剧集行封面与时长角标 (Priority: P1)

用户打开任意订阅详情页，剧集列表每行左侧显示该集 16:9 封面缩略图（圆角），视频时长以角标形式叠在封面右下角（半透明黑底白字，如 `12:34`）；右侧为标题（≤2 行截断）、发布日期、NEW 徽标、已播标记。日期与时长不再挤同一文字行——时长归属封面，文字行只剩日期与状态标记。

**Why this priority**: 「把封面带上」的直接落地，本特性的全部新增价值。

**Independent Test**: 打开任一有剧集的订阅详情页，逐行核对封面、时长角标、标题、日期、NEW/已播标记的显示与位置。

**Acceptance Scenarios**:

1. **Given** 剧集有封面且时长 >0，**When** 列表渲染，**Then** 行左侧显示 16:9 封面缩略图，封面右下角显示时长角标，右侧显示标题+日期+状态标记
2. **Given** 剧集时长为 0（未知），**When** 列表渲染，**Then** 封面正常显示、无时长角标
3. **Given** 剧集无封面（cover 为空），**When** 列表渲染，**Then** 显示既有耳机占位图（CoverThumb 现有行为），无破图
4. **Given** 标题超长，**When** 列表渲染，**Then** 标题最多 2 行、末行省略号截断，行高稳定

---

### User Story 2 - 全功能回归不变 (Priority: P1)

重排后所有既有功能与交互反馈逐项保留：NEW 徽标（pubdate 晚于上次进入时间）、已播标记（本地播放历史命中）、播放全部、手动刷新（含刷新中 Loading 态）、触底加载更早（UP/收藏夹/合集/系列四类翻页链路）、退订二次确认、空态「暂无节目」、行按压态。

**Why this priority**: 「重写」的风险控制线——重排不得丢功能；与 US1 并列 P1，作为回归验收清单。

**Independent Test**: 按 FR-004 清单逐项操作回归，行为与重排前一致。

**Acceptance Scenarios**:

1. **Given** 有新剧集的订阅，**When** 进入详情页，**Then** 新集显示 NEW 徽标（进入后基准刷新逻辑不变）
2. **Given** 已播放过的剧集，**When** 列表渲染，**Then** 显示已播标记
3. **Given** 剧集列表触底，**When** 继续滚动，**Then** 加载更早剧集（四类翻页链路行为不变），到底显示「没有更多了」
4. **Given** 点击删除图标，**When** 确认退订，**Then** 二次确认弹窗行为与现状一致
5. **Given** 手指按压某行，**When** 按下/抬起，**Then** 行背景按压态反馈保留

---

### Edge Cases

- **无封面剧集**：cover 为空 → 耳机占位（CoverThumb 现有形态），时长角标仍按数据正常显示
- **时长未知**：duration ≤0 → 封面无角标，不显示 `0:00`
- **NEW 与已播同现**：同一条目两个标记并存时布局稳定（现排版语义保留）
- **触底加载行/到底行**：「加载中...」「没有更多了」两行不套用新行布局（无封面的辅助行样式不变）
- **空态**：无剧集时「暂无节目」居中展示，不受重排影响
- **长列表性能**：100+ 集订阅滚动流畅，封面图按显示尺寸取缩略档（禁止原图直载）
- **四类订阅一致性**：UP/收藏夹/合集/系列四类源的剧集行布局统一

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 每个剧集行左侧 MUST 显示 16:9 圆角封面缩略图（数据源 `BiliVideo.cover`，现有字段，无新增拉取）；cover 为空时 MUST 显示耳机占位（复用 CoverThumb 现有行为）。
- **FR-002**: 剧集时长 >0 时 MUST 以角标形式叠于封面右下角（半透明深色底 + 白字）；时长 ≤0 时 MUST NOT 显示角标。
- **FR-003**: 右侧文字区 MUST 为「标题（≤2 行，截断）+ 元信息行（日期 + NEW 徽标 + 已播标记）」；时长 MUST NOT 出现在文字行。
- **FR-004**: 以下功能 MUST 逐项保留且行为不变：NEW 徽标、已播标记、播放全部、手动刷新（含 Loading 态）、触底加载更早（四类翻页链路）、退订二次确认、空态、行按压态。
- **FR-005**: 页面头部（56vp 封面 + 副标题 + 集数 + 刷新/删除）MUST 维持现状，不引入大封面 hero 区。
- **FR-006**: 封面图 MUST 按显示尺寸取缩略档（复用 CoverUrl.sized 能力），禁止列表内原图直载。
- **FR-007**: 纯视觉重排：路由（router_map）、数据流（SubscriptionStore/缓存序）、状态管理（@ComponentV2 + @Local）MUST 零改动；色值/尺寸一律 `$r('app.color.*')` / `Constants.TOKEN_*`。

### Key Entities *(include if feature involves data)*

- **剧集条目（BiliVideo，无结构改动）**: 复用现有模型，封面（cover）与时长（duration）均为现有字段，零新增数据依赖。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 有数据（封面非空且时长 >0）的剧集行 100% 显示封面缩略图与时长角标。
- **SC-002**: FR-004 功能清单逐项回归，行为与重排前一致（0 项缺失）。
- **SC-003**: 100+ 集订阅快速滚动无可感知卡顿（封面缩略档加载，无原图直载）。
- **SC-004**: 无封面/无时长/超长标题等边界情形无破图、无布局抖动。

## Assumptions

- 现有共用组件复用：CoverThumb（封面+耳机占位）、CoverUrl.sized（缩略档取图）。
- 四类订阅（UP/收藏夹/合集/系列）剧集数据均含 cover/duration（BiliVideo 现有字段），无新增接口调用。
- 本轮不涉及订阅详情页头部改版、不涉及列表分组/排序等交互变更（如需另行立项）。
- 参照样式：B 站客户端横版列表行（历史记录/收藏夹列表形态）。
