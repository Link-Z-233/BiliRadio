# Feature Specification: 收藏夹功能调整与交互补充（互动豁免/标记常显/入队修复/排序/队列点击/首页色标）

**Status**: Draft
**Input**: v0.7-part4-special-marks 真机验证第二批反馈（收藏夹互动稿被拦无法播放、pill 半透明底叠封面发糊、批量入队确认后界面无响应且无过程提示、多选模式下标记不可见）+ part5 更改内容补充（收藏夹等默认按获取顺序展示并在「更多」新增按时间排序开关、播放列表点击正在播放条目不重载、首页类型色点）+ 增补批次真机反馈两项（「按时间排序」勾选标记移菜单项右侧、源页类型胶囊颜色与首页类型色点一致）

## Overview

对 part4 交付的特殊标记与互动拦截做真机反馈调整，并追加三项交互补充：

1. **收藏夹源互动稿豁免拦截**——收藏夹是用户策展内容（信任用户判断），单击/「+」/批量入队均照常放行走默认路线线性播放；浏览源（UP/合集）与 BV 解析入口保留拦截（收窄 part4 US3「无条件拦截」的收藏夹覆盖面）
2. **pill 底色不透明**——半透底叠封面图发糊，四类 pill 底色 alpha 提满
3. **特殊标记与队列状态标多选模式常显**——源页 pill 与队列/历史标题前缀、行尾 ✓/✗/! 状态标不因多选隐藏（用户拍板，推翻「与既有标记一致隐藏」解读）
4. **批量入队先退多选再异步补全**——修退出动画被详情拉取耗时吞掉；fav 补全期间弹过程提示并忽略重复确认（防重入）
5. **收藏夹/合集/系列默认按获取顺序展示**——去掉统一发布时间降序重排（保留接口返回顺序：收藏夹=收藏时间序、合集/系列=集数序）；「更多」菜单新增「按时间排序」会话级开关（默认关，不持久化，重进源页回默认；选中态以菜单项右侧对号呈现）；UP 源维持发布时间序（双链合并语义，零变化）
6. **播放列表点击正在播放条目无操作**——现状点击正在播放条目会重新取流解析打断播放，改为无操作；点击非当前条目切播行为不变
7. **类型四色标识**——首页订阅行标题前小色点与源页页头类型胶囊按四色区分订阅源类型（UP=蓝、收藏夹=黄、合集=紫、系列=绿；胶囊文字=类型色、底=同色淡底）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 收藏夹互动稿豁免拦截 (Priority: P1)

收藏夹源用户对互动稿件单击/「+」/多选批量入队时照常入队走默认路线线性播放（收藏夹是用户策展内容，信任用户判断）；浏览源（UP/合集）与 BV 解析入口（addSingleVideo）保留互动拦截；豁免仅随收藏夹源传入，不改变其他入口行为。

**Why this priority**: 用户真机反馈收藏夹里的互动稿无法播放——收藏夹是用户主动收藏的策展内容，无条件拦截误伤正常使用场景。

**Independent Test**: 收藏夹单击/批量入队一个互动稿，照常入队可播；同一稿从 UP 源入队仍被拦截。

**Acceptance Scenarios**:

1. **Given** 收藏夹源用户单击或「+」入队互动稿件，**When** 入队执行，**Then** 互动稿照常入队走默认路线线性播放（豁免随 `sub.type === TYPE_FAV` 传入）
2. **Given** 收藏夹源多选批量入队含互动稿件，**When** 详情链补全后入队，**Then** 互动稿照常入队（走默认路线线性播放），队列条目带互动标志
3. **Given** UP/合集源用户对互动视频执行点播或加入队列，**When** 拦截触发，**Then** 不入队、不发起播放，提示互动视频不支持播放类原因（part4 US3 行为保留）
4. **Given** BV 解析入口（addSingleVideo，HomePage/AddSubscriptionSheet 分享导入）添加互动稿，**When** 入队执行，**Then** 保留拦截（不传豁免参，默认 false）

---

### User Story 2 - 标记常显与 pill 不透明 (Priority: P2)

源页四类 pill 底色不透明（半透底叠封面图发糊）；源页 pill、队列/历史标题前缀标记与行尾 ✓/✗/! 状态标在多选模式下保持可见（用户拍板常显，推翻「与既有标记一致隐藏」解读）。

**Why this priority**: 观感与信息可见性——半透底在亮色封面上发糊不可读；多选模式下标记消失导致无法辨识选中条目属性。

**Independent Test**: 打开含特殊稿件列表的多选模式观察标记常显；对照亮色封面观察 pill 底色不透明可读。

**Acceptance Scenarios**:

1. **Given** 源页列表含特殊稿件，**When** pill 渲染，**Then** 四类 pill 底色不透明（`*_pill_bg` alpha FF），任意封面可读
2. **Given** 队列/历史处于多选模式，**When** 含特殊稿件行渲染，**Then** 标题前缀标记与行尾 ✓/✗/! 状态标照常显示，不因多选隐藏（QueueSheet 门控移除）
3. **Given** 非多选模式，**When** 渲染，**Then** 标记显示与 part4 交付一致（零回归）

---

### User Story 3 - 批量入队交互修复 (Priority: P1)

收藏夹多选批量入队确认后立即退出多选（动画即刻起播，对齐队列/历史「先退多选再操作」模式——详情拉取数秒，先入队再退会吞掉退出动画），fav 路径同时弹过程提示（正在补全标志）并在补全在途时忽略重复确认（防重入）。

**Why this priority**: 交互缺陷——批量入队确认后界面无响应数秒（详情补全耗时 + 多选未退），重复点击存在重复入队风险。

**Independent Test**: 收藏夹多选多条确认入队，观察退出动画立即播放、过程提示出现、快速重复确认被忽略。

**Acceptance Scenarios**:

1. **Given** 收藏夹多选批量入队，**When** 确认执行，**Then** 立即退出多选（动画即刻起播）并弹过程提示，选中条目经详情链并行补全标志再入队，队列条目带标志；补全在途时重复确认忽略（防重入）
2. **Given** 批量入队含单条详情失败，**When** 降级入队，**Then** 该条按原列表行入队（无标志、互动不拦），其余条目不受影响（part4 降级语义保留）

---

### User Story 4 - 默认获取顺序与按时间排序开关 (Priority: P1)

收藏夹/合集/系列源列表默认按接口返回顺序展示（收藏夹=收藏时间序、合集/系列=集数序，不再统一按发布时间降序重排）；「更多」菜单新增「按时间排序」开关（会话级，默认关，选中态以菜单项右侧对号呈现），开启时当前列表按发布时间降序重排、关闭恢复获取顺序；开关不持久化，重进源页回到默认获取顺序；UP 源维持现状发布时间序。

**Why this priority**: 收藏夹是用户策展内容，强制发布时间重排抹掉收藏时间序（先收藏的在后面被沉底），列表顺序与用户收藏动作对不上。

**Independent Test**: 收藏夹先收藏一条旧视频再收藏一条新视频，默认列表按收藏时间序排列（新收藏在前）；打开「更多」开启「按时间排序」后按发布时间降序；关闭恢复；退出重进回到收藏时间序。

**Acceptance Scenarios**:

1. **Given** 收藏夹源刷新或进入，**When** 列表渲染，**Then** 按接口返回顺序（收藏时间序）展示，不按发布时间重排
2. **Given** 合集/系列源刷新或进入，**When** 列表渲染，**Then** 按接口返回顺序（集数序）展示
3. **Given** 源详情页「更多」菜单，**When** 打开，**Then** 含「按时间排序」开关，默认关（获取顺序）；开启态在菜单项右侧显示对号，文字与「刷新/取消订阅」左对齐一致，无左侧图标空位
4. **Given** 开关开启，**When** 列表渲染，**Then** 当前列表（含已触底加载的更早条目）按发布时间降序重排，不重新拉取；关闭后恢复获取顺序；重进源页回默认
5. **Given** UP 源，**When** 列表加载/触底追加，**Then** 维持现状发布时间降序（含触底重排），零变化
6. **Given** 开关切换或任一排序模式，**When** 多选/入队/播放等行级交互执行，**Then** 行为正常（重排仅改顺序不改内容）

---

### User Story 5 - 播放列表点击正在播放条目无操作 (Priority: P2)

播放列表中点击正在播放的条目（单条目行/组头行/分P 行）不触发重新加载——播放不中断、不重新取流解析；点击非当前条目照常切播；多选模式下点击仍为选中切换（选择语义不受影响）。

**Why this priority**: 现状缺陷——误触正在播放的条目会重新取流解析打断播放（短暂停顿后从头缓冲），浏览列表时易误触。

**Independent Test**: 播放中打开播放列表点击正在播放条目（组头与分P 行各一次），播放不中断；点击其他条目正常切播。

**Acceptance Scenarios**:

1. **Given** 正在播放条目 X，**When** 非多选模式下点击 X 的行（单条目/组头/分P），**Then** 无操作（不重载、不打断、无状态变化）
2. **Given** 正在播放条目 X，**When** 点击非当前条目 Y，**Then** 照常切播到 Y（现状行为零回归）
3. **Given** 多选模式，**When** 点击正在播放条目，**Then** 照常切换选中（选择语义，无操作规则不生效）
4. **Given** 组头两段判定目标分P 与当前播放分P 一致（如播放 P2 且该组最新历史为 P2），**When** 点击组头，**Then** 无操作

---

### User Story 6 - 类型四色标识：首页色点与源页类型胶囊 (Priority: P2)

首页订阅行标题前显示类型小色点，源页页头类型胶囊同源配色（文字=类型色、底=同色淡底），快速区分订阅源类型：UP=蓝、收藏夹=黄、合集=紫、系列=绿；色点对全部订阅行常显（含新增订阅）。

**Why this priority**: 首页四类源外观一致，混排时无法一眼辨识源类型。

**Independent Test**: 含四类源的首页列表观察标题前色点、进入对应源页观察页头类型胶囊，颜色与类型一一对应且两处同色。

**Acceptance Scenarios**:

1. **Given** 首页订阅列表，**When** 行渲染，**Then** 标题文本前显示类型色点（UP=蓝/收藏夹=黄/合集=紫/系列=绿）
2. **Given** 新增任一类型订阅，**When** 行渲染，**Then** 色点颜色正确对应类型
3. **Given** 编辑态/长按菜单/新集徽标等既有行交互，**When** 操作执行，**Then** 零回归（色点为纯展示元素）
4. **Given** 源页页头类型胶囊，**When** 渲染，**Then** 文字色与淡底按类型四色映射（与首页色点同色），accent 主题色不再用于类型胶囊

---

### Edge Cases

- 豁免仅随收藏夹源传入——UP/合集批量、BV 解析入口、分享导入不豁免
- 防重入标志（enqueueInFlight）仅在 fav 批量补全在途时生效，入队完成后复位
- 多选常显不改变选中态视觉（勾选框/背景），仅移除标记渲染门控
- 排序开关开启时触底加载：追加后整体按发布时间降序重排；关闭（获取顺序）时直接追加尾部不重排
- UP 源触底追加的重排保留（双链合并漂移防乱序）
- 获取顺序模式下 `latestPubAt` 取列表发布时间最大值（获取顺序下首条不再是最新发布，防回退）
- 队列多选模式点击正在播放条目仍为选中切换，无操作规则仅非多选切播路径
- 色点与源页类型胶囊为纯展示元素，不参与行点击/长按/拖拽交互；胶囊颜色仅随类型变化（不随 accent 主题色）

### Non-goals

- 不做入队结果回写源页列表、不做互动跳过 toast 追加提醒（沿 part4 Non-goals）
- 不改 PlayerOverlay（能播放即以既有队列提示呈现）
- 不做收藏夹 order 参数化（最早收藏/最多播放等排序选项），「获取顺序」即当前取数链路返回顺序
- 不做排序开关持久化（会话级，重进源页回默认）
- 不改播放历史（HistorySheet）点击行为
- 不做色点/胶囊可配置、图例说明页

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: `loadPlaylistAndPlay` MUST 增 `allowInteractive` 可选参（默认 false 保持既有拦截）；收藏夹源两入队路径（单击/「+」、批量）MUST 按 `sub.type === TYPE_FAV` 传豁免参，豁免时互动稿照常入队走默认路线；`addSingleVideo`（BV 解析入口）与其他调用方不传参（默认拦截）
- **FR-002**: 四类 `*_pill_bg` color 资源 alpha MUST 提满（不透明），消除半透底叠封面图发糊
- **FR-003**: 队列/历史标题前缀标记与行尾 ✓/✗/! 状态标 MUST 在多选模式常显（QueueSheet `specialMarkPrefix` 与六处状态标 `selectMode` 门控移除，HistorySheet 状态标本无门控）
- **FR-004**: 收藏夹批量入队确认后 MUST 先退出多选再异步补全入队；fav 路径 MUST 弹过程提示（`TOAST_FAV_COMPLETING`）并在补全在途时忽略重复确认（防重入）
- **FR-005**: UP/合集批量与 BV 解析入口行为 MUST 与 part4 交付一致（零回归）
- **FR-006**: 收藏夹/合集/系列刷新与缓存 MUST 保留接口返回顺序（去掉统一发布时间降序重排）；UP 源 MUST 保留重排（APP+Web 双链合并语义）；`latestPubAt` MUST 取发布时间最大值（不再取首条）
- **FR-007**: 源详情页「更多」菜单 MUST 新增「按时间排序」开关（会话级，默认关=获取顺序）；开启时当前列表（含触底已加载条目）按发布时间降序重排且不重新拉取，关闭恢复获取顺序；重进源页回默认（不持久化）；开关选中态 MUST 以菜单项尾部对号呈现（symbolEndIcon），无左侧选中图标空位
- **FR-008**: 播放列表非多选模式下点击复合键等于当前播放条目的行 MUST 无操作（不重载不打断）；点击非当前条目切播行为 MUST 与现状一致（零回归）
- **FR-009**: 首页订阅行标题前 MUST 显示类型色点、源页页头类型胶囊 MUST 同源四色（文字=类型色、底=同色 12% 淡底 tint 令牌）：UP=蓝、收藏夹=黄、合集=紫、系列=绿；色值/尺寸 MUST 令牌化（色彩 `$r('app.color.*')`、数值 Constants）

### Key Entities

- **`allowInteractive` 参数**（`loadPlaylistAndPlay` 第 4 参，默认 false）：豁免互动过滤的单点开关
- **`enqueueInFlight` 标志**（SourcePage）：fav 批量补全防重入
- **`TOAST_FAV_COMPLETING` 常量**（Constants）：fav 批量补全过程提示文案
- **会话级排序开关**（SourcePage 内存态，默认获取顺序）：按时间排序的当次会话开关，重进源页复位
- **获取顺序还原基准**：开关关闭时恢复接口返回顺序所依据的行序记录
- **`sub_type_*` / `sub_type_*_tint` 色彩令牌**（color.json + Constants 尺寸令牌）：四类源类型色（首页色点与源页类型胶囊共用；tint 为 12% 淡底变体）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 收藏夹源互动稿单击/批量 100% 放行入队（走默认路线线性播放）；浏览源与 BV 入口 100% 保留拦截
- **SC-002**: 多选模式下标记与状态标 0 隐藏；pill 底色在任意封面可读（不透明）
- **SC-003**: fav 批量入队确认后退出动画立即播放、过程提示出现、重复确认 0 次重复入队
- **SC-004**: 收藏夹/合集/系列列表 100% 按接口返回顺序展示（默认）；开关切换即时生效 0 次重新拉取；重进源页 100% 回默认；UP 源顺序零变化；开关开启态以菜单项右侧对号呈现（文字左对齐一致）
- **SC-005**: 非多选模式点击正在播放条目 0 次重载（播放不中断）；点击非当前条目 100% 正常切播
- **SC-006**: 首页四类型色点与源页类型胶囊 100% 正确同色显示（含新增订阅），既有行交互零回归

## Assumptions

- 收藏夹互动稿走默认路线线性播放为既定语义（B 站互动视频音频流即主视频音频）
- 豁免仅覆盖互动拦截，门禁码（87007/87008/87005）与大会员 -104 分类不受影响
- 收藏夹接口返回顺序即用户期望的「收藏时间序」（接口默认排序，不额外传 order 参数）
- 合集/系列保持现有倒序取数（sort_reverse），「获取顺序」指当前取数链路返回的顺序
- SourcePage 实例生命周期即「会话」——返回首页再进入视为新会话，开关复位
