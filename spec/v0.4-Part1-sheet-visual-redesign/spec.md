# Feature Specification: 浮层视觉重设计（播放队列 + 播放历史）

**Created**: 2026-10-12  
**Status**: Draft  
**Input**: 用户描述："重新设计并实现 Bottom Sheet（播放队列浮层）在浅色模式和深色模式下的完整视觉效果与交互" + "播放历史也做同样改动"。经澄清：⋯ 菜单与拖拽指示条为误识别，无视；遮罩保留现有分模式配色；文字色改全局令牌；两面板复用同一实现；版本号升至 0.4.0。

## Overview

对播放队列浮层与播放历史面板应用统一的"玻璃浮层"视觉规范：24px 顶部圆角、半透明底色 + 20px 背景模糊、顶部 1px 分隔线、向上投影，两面板（浅色/深色模式）规格完全一致且复用同一实现；弹出动画统一为底部滑入 + 渐显 300ms；列表底部增加 80px 向下渐隐；全局文字色令牌对齐设计稿色阶；版本号升至 0.4.0。既有交互全部保留，不新增任何交互能力。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 播放队列浮层新视觉（浅色模式） (Priority: P1)

用户在浅色模式下打开播放队列浮层，看到符合新规范的面板：顶部左右 24px 圆角、85% 不透明度白色底 + 20px 背景模糊、顶部 1px 黑色 8% 分隔线、向上投影（y -4px / blur 16px / 黑 8%）。

**Why this priority**: 队列浮层是使用频率最高的浮层（首页/播放页均可唤起），是本次重设计的主体。

**Independent Test**: 从首页或播放页打开队列浮层，逐项对照浅色视觉规范核验。

**Acceptance Scenarios**:

1. **Given** 浅色模式且队列有内容，**When** 打开队列浮层，**Then** 面板底色为 85% 白、顶部圆角 24px、顶缘有 1px 黑 8% 分隔线、面板上缘有柔和投影
2. **Given** 队列浮层已打开，**When** 执行左滑删除/多选/清除已播/清空，**Then** 既有交互行为与现在完全一致

---

### User Story 2 - 播放队列浮层新视觉（深色模式） (Priority: P1)

用户在深色模式下打开播放队列浮层：90% 不透明度 #1C1C1E 底 + 20px 模糊、1px 白色 10% 分隔线、投影 y -8px / blur 24px / 黑 50%。

**Why this priority**: 深浅两模式是同一份规范的两组取值，缺一不可。

**Independent Test**: 切换系统深色模式后打开队列浮层，逐项对照深色视觉规范核验。

**Acceptance Scenarios**:

1. **Given** 深色模式，**When** 打开队列浮层，**Then** 底色/分隔线/投影均符合深色规范
2. **Given** 浮层打开状态，**When** 系统外观在浅/深间切换，**Then** 浮层视觉实时跟随切换

---

### User Story 3 - 播放历史面板同步新视觉（复用同一实现） (Priority: P1)

用户从设置页打开播放历史面板，浮层呈现与队列完全相同的视觉规格（浅/深两模式），且两面板由同一套实现承载（复用同一容器组件，非两份平行代码）；既有能力（倒序列表、点击回放、左滑删除、清空二次确认）不变。

**Why this priority**: "同样改动"是用户明确追加的范围，复用代码是用户明确要求，保证两面板永远一致。

**Independent Test**: 设置页 → 播放历史，对照同一份视觉规范核验；回放/删除/清空回归。

**Acceptance Scenarios**:

1. **Given** 浅色模式，**When** 打开播放历史面板，**Then** 视觉规格与队列浮层浅色规范一致
2. **Given** 深色模式且历史有内容，**When** 打开面板并点击任一条目，**Then** 视觉符合深色规范且回放行为与现在一致
3. **Given** 历史面板打开，**When** 清空播放历史，**Then** 二次确认流程与现在一致

---

### User Story 4 - 弹出动画统一（滑入 + 渐显 300ms） (Priority: P2)

任一面板弹出时从底部滑入同时透明度 0→1，时长 300ms；退出为镜像反向动画；遮罩点击关闭保留（遮罩配色维持现有浅 35%/深 55% 分模式，不改 50%）。

**Why this priority**: 动画是新规范明确的交互项，但视觉规格（US1–3）先行验证更直观。

**Independent Test**: 打开/关闭两面板各一次，观察动画为"位移 + 渐显"复合且时长约 300ms；点遮罩可关闭。

**Acceptance Scenarios**:

1. **Given** 面板关闭状态，**When** 唤起面板，**Then** 面板 300ms 内自底部滑入并从透明渐显至完全不透明
2. **Given** 面板打开状态，**When** 点击遮罩，**Then** 面板以反向动画退出后真正关闭
3. **Given** 面板打开状态，**When** 系统返回，**Then** 关闭行为与现在一致

---

### User Story 5 - 列表底部渐隐 (Priority: P3)

播放列表/历史列表最后一项下方有高度 80px 的向下渐隐：从透明渐变到对应模式的浮层背景色，尾条目自然消隐于面板底缘。

**Why this priority**: 纯装饰性细节，不影响功能，优先级最低。

**Independent Test**: 打开有长列表的面板，滚动到底，观察最后一项下方 80px 渐隐带。

**Acceptance Scenarios**:

1. **Given** 队列/历史列表滚动到底部，**When** 最后一项进入可视区，**Then** 其下方呈现 80px 从透明到浮层背景色的渐隐
2. **Given** 队列/历史为空，**When** 打开面板，**Then** 空态提示正常呈现，不出现异常色块

---

### User Story 6 - 全局文字色对齐设计稿色阶 (Priority: P2)

全局文字色令牌调整为设计稿色阶：浅色主 #1A1A1A→#1D1D1F、次 #666666→#6E6E73；深色主 #FFFFFF→#F5F5F7、次 #B3B3B8→#8E8E93。全应用所有使用这两个令牌的页面同步生效（用户已确认接受全应用波及）。

**Why this priority**: 用户明确选择"改全局令牌"方案；浮层内文字色依赖它达标，早于装饰性细节。

**Independent Test**: 浅/深模式下浏览首页、设置页、播放页等任意页面，文字色为新色阶且无对比度异常。

**Acceptance Scenarios**:

1. **Given** 深色模式，**When** 打开任意页面，**Then** 次要文字（副标题/时间等）为 #8E8E93（较原先 #B3B3B8 更暗更灰）
2. **Given** 浅色模式，**When** 打开任意页面，**Then** 主文字 #1D1D1F、次文字 #6E6E73，与原先差异不可感知但已对齐设计稿
3. **Given** 任意页面存在禁用态文字，**When** 查看，**Then** 禁用态/占位色视觉和谐，无对比度问题

---

### User Story 7 - 版本号升至 0.4.0 (Priority: P3)

应用版本号自 0.3.0 升至 0.4.0（versionCode 3000→4000），标识本轮用户可感知的视觉改版。

**Why this priority**: 例行发布动作，跟随本轮一起出，优先级最低。

**Independent Test**: 构建后查看"关于"页显示 0.4.0。

**Acceptance Scenarios**:

1. **Given** 本轮改动完成，**When** 查看应用版本信息，**Then** versionName 为 0.4.0、versionCode 为 4000

### Edge Cases

- 队列浮层挂载于首页内容层与播放页两层，视觉与动画必须一致
- 多选模式头部替换、左滑删除按钮等状态切换在新视觉下正常
- 面板打开时切换浅/深外观，实时跟随
- 渐隐层不遮挡列表末尾条目的点击/滑动操作
- 极短列表（1–2 项）下渐隐与面板布局不冲突
- 全局文字色调整后，所有引用 text_primary/text_secondary 的页面无对比度/可读性回归

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 两面板顶部左右圆角 MUST 为 24px，其余角为直角
- **FR-002**: 浮层底色与背景模糊——浅色：#FFFFFF 85% 不透明度 + 20px 模糊；深色：#1C1C1E 90% 不透明度 + 20px 模糊；两面板取值一致
- **FR-003**: 浮层顶部边缘 MUST 有 1px 分隔线——浅色：#000000 8% 不透明度；深色：#FFFFFF 10% 不透明度
- **FR-004**: 浮层 MUST 带向上投影——浅色：y -4px / blur 16px / #000000 8%；深色：y -8px / blur 24px / #000000 50%
- **FR-005**: 全局文字色令牌 MUST 调整为——浅色：text_primary #1D1D1F、text_secondary #6E6E73；深色：text_primary #F5F5F7、text_secondary #8E8E93；全应用生效
- **FR-006**: 弹出动画 MUST 为底部滑入 + 透明度 0→1 复合动画，时长 300ms；退出为镜像反向；遮罩点击关闭，遮罩配色保留现有浅/深分模式取值
- **FR-007**: 列表最后一项下方 MUST 有 80px 向下渐隐（透明 → 浮层背景色），且不拦截列表交互
- **FR-008**: 播放历史面板 MUST 应用与队列浮层完全相同的视觉规范（FR-001～FR-007），且 MUST 与队列浮层复用同一容器实现（同一组件，非两份平行代码）
- **FR-009**: 既有交互 MUST 全部保留：队列（头部清除已播/多选/清空按钮、左滑删除、多选批量移除、点击切播）；历史（点击回放、左滑删除、清空二次确认）；两面板的遮罩点击关闭与系统返回关闭
- **FR-010**: 明确排除项（经用户澄清，不实现）：⋯ 更多菜单、拖拽指示条、指示条/列表顶部拖拽关闭手势、遮罩改 50% 统一色、面板私有文字色资源
- **FR-011**: 应用版本号 MUST 升至 versionName 0.4.0、versionCode 4000

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 浅色与深色模式下，两面板全部视觉属性（底色/模糊/圆角/分隔线/投影）可逐项对照设计规范核验通过
- **SC-002**: 弹出动画在 300ms 内完成"位移 + 渐显"复合过渡，退出为反向动画
- **SC-003**: FR-009 列举的全部既有交互回归无缺失
- **SC-004**: 全局文字色为新色阶，全应用无对比度/可读性回归
- **SC-005**: 版本信息显示 0.4.0 / 4000
- **SC-006**: 构建通过（devecocli build）

## Assumptions

- "同样改动" = 历史面板应用完整视觉规范（FR-001～FR-008 全量），复用代码是硬性要求
- 队列浮层退出动画沿用现有反向滑出机制，仅时长/渐显对齐新规范
- 面板高度维持现状（队列 65%、历史约 62%），设计稿未涉及
- 文字色仅调 text_primary/text_secondary 两令牌，text_disabled/placeholder 等其他色令牌不动（设计稿未涉及）
- 历史面板现状为系统 bindSheet，将转为与队列同构的共用浮层实现；用户可感知行为（打开/关闭路径、内容）不变

## Open Questions

- 无（文字色方案与版本号已确认；历史面板实现方式已定为复用队列容器）
