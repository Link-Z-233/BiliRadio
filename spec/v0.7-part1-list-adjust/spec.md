# Spec: 队列插入位置控制（v0.7-part1）

**Input**: User requests: ① 进入 v0.7，版本号 0.6.0→0.7.0（versionCode 6000→7000）；② 队列面板多选模式新增「下一首播放」「移到最后」批量移动操作；③ 订阅源页多选底部栏新增「下一首播放 (N)」批量入队按钮，「标记已看完」移至中间，原「加入队列 (N)」更名「队列末播放 (N)」（追加队尾语义不变）；④ 订阅源页单击剧集的入队插入位置由新「单集插入位置」设置控制（下一首播放/队列末播放），默认「队列末播放」保持现状，空队列照旧起播，设置仅对单曲点击生效；⑤ 队列面板单行头部「清除已播」「清空」两枚按钮位置互换（Phase 2 审查追加）；⑥ 队列与历史两面板多选行的选中计数改为全选按钮右侧独立展示，移除/删除所选按钮去内嵌计数（Phase 2 审查追加）；⑦ 两面板多选行全部图标按钮长按提示功能说明——按钮处 bindPopup 气泡、点面板任意处消失（再优化批定 toast、第三修正改气泡）；⑧ 多选计数改「已选N条」格式——N 主题色、其余字黑色、字号同面板标题（再优化批）；⑨ 队列移动完成后 toast 通知，推翻原「移动无 toast」（再优化批）；⑩ 队列移动加列表重排动画——移动条目飞越其他条目上方（z 序提升），机制源于⑫首页置顶飞越、在其后实施（再优化批）；移动飞越与退出多选动画同时进行（第三修正）；⑪ 源页底栏 下一首播放/队列末播放 位置互换且样式一致——双 accent 主按钮（下一首播放右侧、队列末播放左侧），中 标记已看完 card 底 accent 描边（再优化批第三修正）；⑫ 首页置顶移动动画调整——被置顶行飞行期间从其他条目上方飞越（z 序提升盖在其他行上）至首位，其余行向下补位（再优化批追加）。经逐项澄清确认：队列移动走多选批量（非长按单条菜单）；多选按钮为显式操作不受设置影响；入队按钮保留选中计数 (N)；长按提示覆盖两面板多选行全部图标按钮；底栏互换后双按钮均加主色；第三修正——底栏左右入队按钮统一 accent 主按钮、中 card 底主题色描边，移动飞越与退出多选动画同时进行，长按提示改按钮处气泡。

**Output**: 全部交付——队列多选批量移动（含完成 toast、与退出多选同时进行的飞越动画）、源页多选三按钮底栏（左右双 accent 主按钮、中 card 底主题色描边）、单集插入位置设置（含持久化）、队列头部按钮位序互换、两面板多选「已选N条」独立计数、两面板多选行长按气泡提示、首页置顶飞越动画、版本号 0.7.0/7000。

**Context**: v0.6 四轮已完结（master `dc519d0`）；feature.json 指向 v0.6-part4-removal-confirm，本轮切至本目录。本轮开发在主分支 `master` 进行（不另建分支）。现状关键事实：队列面板多选已有「移除所选」，条目无重排能力；源页多选底栏现为两按钮（标记已看完/加入队列 N）；单击入队走 `loadPlaylistAndPlay`（空队列起播、非空追加队尾、重复跳过）；播放模式有顺序/随机/单曲循环/倒序四种。

## User Stories

### US1 队列多选批量移动 (Priority: P1) 🎯 MVP

队列面板多选模式下，对选中条目提供两个批量移动操作：「下一首播放」——选中条目按原相对顺序整体移至当前播放条目之后；「移到最后」——选中条目按原相对顺序整体移至队列末尾。移动为就地重排，不打断当前播放；列表重排带飞越动画——移动条目飞行期间 z 序提升盖在其他条目之上（机制同 US7 置顶飞越），其余条目补位，退出多选动画与飞越动画同时进行（同起同落），移动完成后 toast 通知结果。

**Why this priority**: 队列条目目前只有删除能力，无任何重排能力；这是本轮唯一新增的队列管理能力，独立可用。

**Independent Test**: 队列 ≥3 条目时多选若干条目分别执行两种移动，队列顺序带动画即时变化、toast 提示移动结果、播放不打断。

1. **Given** 队列 ≥3 条目且有当前播放条目, **When** 多选若干非当前条目执行「下一首播放」, **Then** 选中条目按原相对顺序紧随当前播放条目之后，未选中条目相对顺序不变，播放不打断
2. **Given** 同上, **When** 执行「移到最后」, **Then** 选中条目按原相对顺序移至队列末尾，未选中条目前移补位，播放不打断
3. **Given** 选中集合包含当前播放条目, **When** 执行任一移动, **Then** 当前播放条目原位不动，其余选中条目正常移动
4. **Given** 选中条目含多 P 组, **When** 移动, **Then** 该组作为整体移动，组内分 P 保持连续完整
5. **Given** 移动完成, **When** 观察, **Then** 退出多选模式（与飞越动画同起同落）且 toast 通知移动结果（「已插入 N 项到当前播放之后」/「已移动 N 项至队尾」）（对齐「移除所选」后交互）
6. **Given** 移动执行, **When** 观察列表, **Then** 被移动条目飞行期间 z 序提升盖在其他条目之上飞至新位置（飞越动画，非瞬跳），其余条目补位，动画结束 z 序复位

### US2 源页多选「下一首播放 (N)」 (Priority: P2)

订阅源页多选底部操作栏由两按钮扩为三按钮（再优化批位序、第三修正样式）：左「队列末播放 (N)」（accent 主按钮，追加队尾，原「加入队列 (N)」更名语义不变）·中「标记已看完」（card 底 + 主题色描边）·右「下一首播放 (N)」（accent 主按钮，选中剧集按列表序批量入队并插至当前播放条目之后）；两枚入队按钮样式一致。

**Why this priority**: 批量入队目前只能追加队尾；设置仅单曲生效（US3），多选需显式按钮指定插入位置。

**Independent Test**: 队列非空时多选剧集点「下一首播放 (N)」，选中剧集入队且紧随当前播放条目。

1. **Given** 队列非空, **When** 多选剧集点「下一首播放 (N)」, **Then** 选中剧集按列表序插入当前播放条目之后，不打断播放
2. **Given** 队列为空, **When** 同上, **Then** 起播选中剧集（与「队列末播放」空队列语义一致）
3. **Given** 无选中, **When** 底部栏渲染, **Then** 三按钮共享禁用（现有模式）
4. **Given** 任意多选状态, **When** 底部栏渲染, **Then** 布局为三按钮：「队列末播放 (N)」居左（accent 主按钮）、「标记已看完」居中（card 底主题色描边）、「下一首播放 (N)」居右（accent 主按钮）——两枚入队按钮样式一致
5. **Given** 选中剧集已在队列中, **When** 点「下一首播放 (N)」, **Then** 重复条目按现有语义跳过，其余正常插入

### US3 单集插入位置设置 (Priority: P2)

设置页新增「单集插入位置」设置项（两项：下一首播放/队列末播放），默认「队列末播放」（与现状一致）。仅影响订阅源页单击剧集的入队位置：队列为空任何设置下照旧立即起播；非空时按设置插入。

**Why this priority**: 单击是最高频入队路径，插入位置偏好个性化；默认保持现状，升级用户无感。

**Independent Test**: 切换设置后在源页单击不同视频，插入位置随设置即时变化且持久化。

1. **Given** 设置「队列末播放」（默认）, **When** 队列非空时单击源内视频, **Then** 追加队尾（现状零变化）
2. **Given** 设置「下一首播放」, **When** 同上, **Then** 该视频（多 P 展开全部分 P）插入当前播放条目之后
3. **Given** 队列为空（任意设置）, **When** 单击源内视频, **Then** 照旧立即起播
4. **Given** 切换设置后重启应用, **When** 再看设置, **Then** 状态保持（持久化）
5. **Given** 设置「下一首播放」, **When** 源页多选批量入队或添加订阅入队, **Then** 不受该设置影响（多选为显式按钮、添加订阅维持现状追加）

### US4 队列头部按钮位序互换 (Priority: P3)

队列面板单行头部右侧三枚图标按钮位序调整：「清空」（trash）与「清除已播」（wand_and_stars）位置互换，新序为 清空 → 多选 → 清除已播。图标、功能、样式、确认弹窗均不变，仅位置。

**Why this priority**: 用户在 Phase 2 审查中提出的观感调整，纯布局零逻辑。

**Independent Test**: 打开队列面板，头部右侧图标序为 清空、多选、清除已播，各按钮功能与互换前一致。

1. **Given** 队列非空, **When** 打开队列面板, **Then** 头部右侧图标序为 清空 → 多选 → 清除已播
2. **Given** 互换后任一按钮, **When** 点击, **Then** 功能与互换前一致（清空弹二次确认/多选进多选态/清除已播弹二次确认）

### US5 多选计数独立展示 (Priority: P3)

队列与历史两面板多选行的选中计数展示调整：计数从移除/删除所选按钮内移出，改为在全选按钮右侧独立展示，格式「已选N条」——N 主题色、其余字黑色（text_primary）、字号与面板标题一致，随勾选实时变化；两面板同步调整（同一档式）。移除/删除所选按钮变为纯图标，功能与确认弹窗不变。

**Why this priority**: 用户在 Phase 2 审查中提出的展示调整；队列/历史两面板多选交互对齐的延续。

**Independent Test**: 两面板分别进入多选勾选条目，全选按钮右侧出现「已选N条」计数并实时变化，移除/删除按钮不再内嵌计数。

1. **Given** 队列面板进入多选, **When** 勾选/取消条目, **Then** 全选按钮右侧「已选N条」随勾选实时变化（0 也显示「已选0条」）
2. **Given** 历史面板进入多选, **When** 同上, **Then** 同上（两面板同档式）
3. **Given** 两面板多选态, **When** 观察移除/删除所选按钮, **Then** 纯图标、无内嵌计数，点击功能与确认弹窗不变

### US6 多选行图标按钮长按提示 (Priority: P3)

队列与历史两面板多选行的全部图标按钮支持长按在按钮处弹 bindPopup 气泡提示功能说明（气泡锚定按钮、点面板任意处消失；队列：全选/移除/移到最后/下一首播放/退出；历史：全选/删除所选/返回），短按行为不变。

**Why this priority**: 多选行全图标化后功能语义仅凭图标辨识，长按提示补足可发现性（用户再优化批提出）。

**Independent Test**: 两面板多选行逐枚长按图标按钮，按钮处弹出对应功能说明气泡，短按功能正常。

1. **Given** 队列多选行任一图标按钮, **When** 长按, **Then** 按钮处弹气泡显示该按钮功能说明（全选/移除所选/移到最后/下一首播放/退出多选）
2. **Given** 历史多选行任一图标按钮, **When** 长按, **Then** 按钮处弹气泡显示该按钮功能说明（全选/删除所选/退出多选）
3. **Given** 长按气泡弹出后, **When** 点面板任意处或短按同按钮, **Then** 气泡消失、功能正常执行，长按与短按无冲突

### US7 首页置顶飞越动画 (Priority: P3)

首页订阅列表「置顶」操作的移动动画调整：被置顶行飞行期间从其他条目上方飞越（z 序提升盖在其他行之上）直达首位，其余行向下补位收拢；不在首位互换式的交换视觉下穿行。已在首位幂等无变化（现状）。

**Why this priority**: 用户在再优化批中提出的置顶动画观感调整（置顶行应像「抽卡片压到最上面」，而非从底部路径穿行）。

**Independent Test**: 订阅列表 ≥3 行时对非首位行执行置顶，该行盖在其他行上方飞至首位，其余行下移补位，动画结束布局正确。

1. **Given** 订阅列表 ≥3 行, **When** 长按非首行弹菜单点「置顶」, **Then** 该行从原位置起飞、飞行期间渲染于其他行之上（z 序提升），到达首位，其余行向下补位
2. **Given** 动画结束, **When** 观察, **Then** z 序复位、布局与数据一致（首位为被置顶行），点击/长按/拖拽排序等功能正常
3. **Given** 对首位行置顶, **When** 执行, **Then** 幂等无变化（现状）

## Functional Requirements

- **FR-001**: 队列面板多选模式 MUST 提供批量移动操作「下一首播放」与「移到最后」：选中条目按原相对顺序整体移至当前播放条目之后 / 队列末尾；选中集合包含当前播放条目时该条目跳过不移动
- **FR-002**: 批量移动 MUST 保持多 P 组完整（组整体移动）、不打断当前播放；列表重排 MUST 带飞越动画——被移动条目飞行期间 z 序提升盖在其他条目之上、其余条目补位、动画结束 z 序复位（机制同 FR-012 置顶飞越）；退出多选动画 MUST 与飞越动画同时进行（同一起点同步驱动）；完成后 MUST toast 通知移动结果（「已插入 N 项到当前播放之后」/「已移动 N 项至队尾」）
- **FR-003**: 订阅源页多选底部操作栏 MUST 为三按钮布局——左「队列末播放 (N)」（accent 主按钮，追加队尾）/「标记已看完」（居中，card 底 + 主题色描边）/右「下一首播放 (N)」（accent 主按钮，批量入队插至当前播放之后）；两枚入队按钮样式一致；无选中时三按钮共享禁用（现有模式）
- **FR-004**: 「下一首播放 (N)」空队列时 MUST 起播选中内容；非空时队列已有重复条目按现有语义跳过后插入
- **FR-005**: 设置页 MUST 新增「单集插入位置」设置（下一首播放/队列末播放），默认「队列末播放」，状态持久化
- **FR-006**: 订阅源页单击剧集 MUST 按设置插入：队列空照旧立即起播；非空时「队列末播放」追加队尾（现状语义）、「下一首播放」将目标视频（多 P 展开全部分 P）插入当前播放条目之后，重复条目按现有语义跳过
- **FR-007**: 该设置 MUST 仅影响单击入队路径；源页多选按钮、添加订阅入队、历史面板、队列内点播等其余入队/播放路径行为不变
- **FR-008**: 版本号 MUST 升至 versionName 0.7.0 / versionCode 7000
- **FR-009**: 队列面板单行头部右侧按钮位序 MUST 调整为 清空 → 多选 → 清除已播（图标、功能、样式、确认弹窗不变，仅位置互换）
- **FR-010**: 队列与历史两面板多选行 MUST 将选中计数改为全选按钮右侧独立展示，格式「已选N条」——N 主题色、其余字 text_primary、字号同面板标题（0 也显示）；移除/删除所选按钮去内嵌计数变纯图标，功能与确认弹窗不变
- **FR-011**: 队列与历史两面板多选行全部图标按钮 MUST 支持长按在按钮处弹 bindPopup 气泡功能提示（提示文案=按钮功能名：队列 全选/移除所选/移到最后/下一首播放/退出多选，历史 全选/删除所选/退出多选；气泡锚定被长按按钮、点面板任意处消失），短按行为不变
- **FR-012**: 首页「置顶」移动动画 MUST 使被置顶行飞行期间 z 序提升（渲染于其他行之上）飞至首位、其余行向下补位；动画结束 z 序复位；首位幂等无变化

## Edge Cases & Design Considerations

- 「下一首播放」指队列线性位置（当前播放条目之后）；实际播放顺序仍由播放模式决定——随机播放为条目级随机抽取，不保证紧随播放；单曲循环仍循环当前条目。规格仅承诺插入位置正确
- 队列仅当前播放一条目（其余为空）时：「下一首播放」= 紧随其后（等效队尾），两操作结果一致，均正常执行
- 单击「下一首播放」设置下点已出队/已播完条目：仍按插入语义处理（重入队插当前后），已播标记不受影响
- 移动完成后 toast 通知移动结果（FR-002 文案）；入队类操作沿用现有「已加入队列/开始播放/已在队列中」三分型 toast
- 队列飞越与置顶飞越（FR-002/FR-012）同一机制观感（z 序提升飞行、结束复位），不抽公共组件、各自实现（用户决策）；实施序置顶先行、队列复用其机制
- 飞越仅承诺 z 序观感（飞行条目盖在其他条目上、结束复位）；scale/阴影等「抬起」微调不承诺，真机观感不足再议；队列广播链时序致动画不生效时降级无动画不阻塞功能
- 长按气泡与短按并存：长按只在按钮处弹气泡不触发按钮功能，气泡点面板任意处消失（autoCancel）；短按照常执行，气泡弹出后首次点击可能先关气泡再执行功能（真机核验项）；长按时长沿用系统默认阈值
- 设置项在设置页的分组归属与文案细节由 plan 阶段定；存储键沿用 `KEY_*`/`AS_*` 双轨惯例
