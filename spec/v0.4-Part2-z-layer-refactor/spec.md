# Feature Specification: 四层 z 序重构（设置/日志去路由 + 队列单挂载 + 胶囊覆盖语义）

**Created**: 2026-10-13
**Status**: Draft（规划轮产出；Phase 4/5 实施与验证移交后续对话执行）
**Input**: 用户指令：「做层级关系，首页的订阅列表和它的二级页订阅源详情在第一层，miniplayer 在第二层，播放页在第三层，播放列表页在第四层，设置页及其附属内容在第五层」「高层内容直接覆盖低层内容，这样不用做退出了」+ 修正案：「设置层放到第二层，首页和 miniplayer（因为他俩之间没有悬浮关系）同在第一层」+ 定案：「历史面板留设置层（L2），不与队列同级」+ 三项批准变更（未登录音质显示 64K / 账号栏大会员标识 / 历史与日志去计数）

## Overview

将应用界面元素重组为严格四层 z 序栈：高层物理覆盖低层，彻底消除「退出设置页时播放胶囊突然出现」的 bug。该 bug 根因是胶囊悬于全栈顶部，依赖 400ms 定时器对齐导航退场时序——属打地鼠式时序修补。重构后设置页与日志页退出系统路由改为层级条件渲染，队列面板收敛为单一挂载点，胶囊显隐的全部定时器/标志/动画机制随覆盖语义退役。历史面板维持设置页树内承载（L2），点播行为与现状一致。另含三项经批准的小幅可见变更：未登录音质档位显示 64K 并引导登录、账号栏大会员标识、历史/日志计数移除。

## Layer Model（层序契约，本轮核心不变量）

| 层 | 内容 | 说明 |
|---|---|---|
| L1（最底） | 导航层：首页订阅列表 + 订阅源详情二级页（保留系统路由转场）+ 底部播放胶囊 | 胶囊恒挂载恒可见（空态显示「暂无播放内容」占位条），被上层物理覆盖 |
| L2 | 设置层：设置页（含播放历史/音质/关于/账号等附属）+ 日志页（设置附属，渲染于设置层之上） | 去路由改层级条件渲染 |
| L3 | 播放层：全屏播放浮层（含倍速/模式/睡眠定时/音质/详情附属面板） | 承载机制不变 |
| L4（最顶） | 队列层：播放列表面板 | 单一挂载点 |

**覆盖规则**：高层内容直接覆盖低层；层间不保留任何「退出时序」机制（定时器、延时标志翻转、显隐等待动画）。唯一例外：队列层与播放层之间现存的下滑退出手势判定保留（队列在台时播放层下滑关闭不触发）。

**修订注记（历史面板独立层 + 插播式点播，后续轮次）**：上表 L2 中「含播放历史」及 Input 定案「历史面板留设置层（L2），不与队列同级」已被后续轮次取代——历史面板升级为 Index 单一挂载的独立层（新五层：L1 导航+胶囊 → L2 设置+日志 → L3 播放浮层 → L4 历史面板 → L5 队列），入口仍在设置页；点历史条目改为起播后唤起播放浮层（层序在历史面板之下，收起面板即见），面板不收，且不在队列的条目改为插入当前播放条目之前起播（插播，播完回到原当前条目）；`goToPlayerTab` 整链随「点播进播放页」中转行为一并退役。

## User Scenarios & Testing

### User Story 1 - 退出设置页胶囊不再突现 (Priority: P1)

用户从首页进入设置页：设置层从右侧滑入，从第一帧起完整覆盖底部胶囊；返回时设置层右滑退出，胶囊随滑出逐帧自然揭示。无「等待转场结束后突然浮现」，无快速往返竞态。

**Why this priority**: 本轮重构的直接动因。现存 bug 的修补链（在台标志 + 退场定值延时 + 显隐动画 + 竞态消解）已迭代三轮仍在打地鼠，根因是 z 序而非时序。

**Independent Test**: 播放中反复进出设置页（含快速往返），观察设置层滑出全程胶囊的可见性过渡。

**Acceptance Scenarios**:

1. **Given** 播放中，**When** 首页点右上「更多」进设置，**Then** 设置层滑入全程胶囊被覆盖，无动画闪现
2. **Given** 设置页在台且播放中，**When** 点返回按钮或系统返回，**Then** 胶囊随设置层滑出逐帧露出，无延时后突现
3. **Given** 进设置立刻返回（快速往返），**Then** 无残影、无错序、无标志残留（原竞态修补代码已整体删除）

---

### User Story 2 - 设置/日志入口行为不变 (Priority: P1)

设置页与日志页改层级承载后，除三项经批准的显式变更（US5 音质显示 / US7 大会员标识 / US8 计数移除）外，全部用户可感知行为与现状一致：入口位置、滑入方向、返回关闭语义、页内全部功能（账号登录/播放历史/音质/外观/调试/关于/日志查询导出清空）零变化。

**Why this priority**: 重构红线——只换承载机制，不换用户行为；除批准清单外，任何可感知变化均视为回归。

**Independent Test**: 逐项走查设置页所有分组与附属面板（含日志页进出），对照重构前行为。

**Acceptance Scenarios**:

1. **Given** 首页，**When** 点右上「更多」，**Then** 设置层右滑入
2. **Given** 设置页，**When** 点「日志查询」入口，**Then** 日志层在设置层之上滑入；返回仅关日志层，设置层保持
3. **Given** 日志层清空/导出后返回设置页，**Then** 设置页功能状态正常（日志入口不再显示条数计数，见 US8）
4. **Given** 设置页在台，**When** 系统返回，**Then** 仅设置层关闭，下层保持原状

---

### User Story 3 - 历史点播与分层返回链 (Priority: P1)

设置页播放历史面板点条目点播：播放浮层在设置层之上滑入（L3 > L2），返回先关浮层、设置层（含历史面板状态）保持——与现状完全一致。系统返回键按「当前最上层优先」逐层关闭。

**Why this priority**: 历史点播是设置层与播放层交互的唯一交叉点，层序设计必须保证该场景零回归；返回链是层级架构的行为骨架。

**Independent Test**: 设置页历史面板点播→返回→再返回，观察浮层与设置层的开合次序。

**Acceptance Scenarios**:

1. **Given** 设置页历史面板开，**When** 点历史条目，**Then** 播放浮层覆盖设置层滑入并开始播放
2. **Given** 浮层开于设置层之上，**When** 系统返回，**Then** 仅浮层关闭，设置层（含历史面板状态）保持；再返回才关设置层
3. **Given** 播放浮层 + 队列面板同开，**When** 返回，**Then** 先关队列（多选态先退多选）、再关浮层
4. **Given** 设置页音质选择器/历史面板开，**When** 返回，**Then** 先关面板再关设置层

---

### User Story 4 - 队列单挂载点 (Priority: P2)

队列面板从播放页按钮与胶囊按钮两处入口打开，均由同一 L4 层承载：开于播放层之上时视觉与现状一致（面板+遮罩盖住播放页）；开于首页时从底部滑入盖住首页与胶囊。

**Why this priority**: 消除现存的双挂载（Index 内容层 + PlayerOverlay 内部层各一份 GlassSheet），双挂载是模块级注册 hack 的存在根源，收敛后机制自然简化。

**Independent Test**: 两个入口分别开队列，对照重构前面板位置、遮罩范围、关闭动画。

**Acceptance Scenarios**:

1. **Given** 播放浮层在台，**When** 点队列按钮，**Then** 队列面板盖在播放层之上滑入（与现状一致）
2. **Given** 首页（播放中），**When** 点胶囊队列按钮，**Then** 队列面板从底部滑入盖住首页与胶囊（与现状一致）
3. **Given** 队列开于浮层之上，**When** 系统返回，**Then** 队列先于浮层关闭

---

### User Story 5 - 未登录音质档位显示 (Priority: P2)

播放浮层音质面板：当前内容提供多音轨时展示实际音轨列表（现状不变）；未提供时（典型为未登录取流，仅 64K 兜底流），音质档位显示「64K」而非「默认」，说明文案改为引导登录（如「登录后可选更高音质」）。

**Why this priority**: 「默认」不传达任何音质信息；如实显示 64K 并引导登录，用户可据此判断是否需要登录提升音质。

**Independent Test**: 未登录与登录两态分别打开播放浮层音质面板，对照档位显示与文案。

**Acceptance Scenarios**:

1. **Given** 未登录播放中，**When** 打开音质面板，**Then** 档位显示「64K」（非「默认」），附登录引导文案
2. **Given** 已登录播放中，**When** 打开音质面板，**Then** 展示实际音轨列表（与现状一致）
3. **Given** 未登录，**When** 经面板提示完成登录并重取流，**Then** 音质面板恢复多音轨列表

**修订注记（音质轮，后续轮次）**：US5/FR-009 的 durl 态展示已被后续轮次取代——durl 兜底流（无档位概念）音质面板改显示「默认」单选项（含入口标签），原「64K + 登录引导」文案退役；播放页空闲态（冷启动未播放）优先显示缓存的上次实际档（新键 `KEY_LAST_QUALITY`，与进度同保存点持久化），无缓存/清空过回退当前网络设置默认档；默认音质选择器为大会员补 Hi-Res(30251)/杜比(30250) 两档（非大会员不显示，视频不提供所选高档时 `pickAudioTrack` 按回落上限 192K 兜底）。

---

### User Story 6 - 机制净删除 (Priority: P3)

胶囊显隐的时序修补机制全部退役：设置页在台标志、导航退场定值延时（400ms）、胶囊显隐动画时长（250ms）、胶囊可见性全局键及其三页消费逻辑、日志条数缓存（logCount 成员及其加载/刷新）。三处滚动页底部避让 padding 静态化——取值与现状恒真分支一致（胶囊恒可见含空态占位条，静态预留本就是现状的实际行为）。

**Why this priority**: 重构的收益兑现——删除是本轮的净产出；padding 静态化因胶囊空态占位条恒可见而成立（冷启动首页即有占位条 + 预留）。

**Independent Test**: 冷启动与清空队列两个空态场景，对照底部占位与预留行为。

**Acceptance Scenarios**:

1. **Given** 冷启动无播放内容，**Then** 胶囊显示「暂无播放内容」占位条，首页底部预留与现状一致
2. **Given** 播放中清空队列，**Then** 胶囊转空态占位条（现状行为，非隐藏）
3. **Given** 全仓检索退役键/常量名，**Then** 零残留

---

### User Story 7 - 账号栏大会员标识 (Priority: P3)

设置页账号栏：登录且账号为大会员（vipStatus 为有效大会员状态）时，昵称旁显示大会员标识，样式贴近 B 站官方视觉；非大会员登录账号不显示；未登录不显示（账号栏维持登录入口现状）。

**Why this priority**: 大会员身份影响可选音质档位，在账号栏如实展示有助于用户理解音质可选项差异。

**Independent Test**: 分别以大会员账号、普通账号、未登录三态查看设置页账号栏。

**Acceptance Scenarios**:

1. **Given** 大会员账号已登录，**When** 查看设置页账号栏，**Then** 昵称旁显示大会员标识
2. **Given** 普通账号已登录，**When** 查看账号栏，**Then** 无大会员标识
3. **Given** 未登录，**When** 查看账号栏，**Then** 显示登录入口（现状），无标识

---

### User Story 8 - 列表计数移除 (Priority: P3)

播放历史面板标题、设置页播放历史入口行、日志查询入口行不再显示条数计数（「(N)」「N 条」字样移除）；计数相关的缓存与刷新机制随展示一并删除。

**Why this priority**: 计数信息价值低且引入额外刷新机制（日志层关闭时刷新角标）；移除后信息架构更干净、机制更少。

**Independent Test**: 有/无历史记录、有/无日志两态分别查看对应位置。

**Acceptance Scenarios**:

1. **Given** 有 N 条播放历史，**When** 打开历史面板/查看设置页历史入口行，**Then** 标题与入口行均无「(N)」「N 条」计数字样
2. **Given** 日志层执行清空/导出后返回，**Then** 日志入口行无计数，无计数刷新行为
3. **Given** 零历史/零日志，**Then** 展示与有数据时仅差列表内容本身，无空计数占位

---

### Edge Cases

- 浮层开于设置层之上（历史点播）时按返回：先关浮层（高层优先），设置层不动
- 深栈场景（设置层 + 历史面板 + 浮层 + 队列逐层同开）：现状既有路径，返回链逐层关闭次序正确
- 设置层快速滑入/滑出：胶囊即被覆盖/揭示，无竞态窗口（原竞态源码整体删除，非修补）
- 清空队列两标志同收（clearBothLayersNow）语义不变：标志驱动，与挂载位置无关
- 关于页/详情页等 bindSheet 附属：系统返回由 bindSheet 原生拦截，不进自定义返回链
- 播放层下滑退出手势：队列在台（L4 盖于其上）时仍不触发浮层下滑关闭（现有 noOverlayOpen 判定保留队列标志）
- 订阅源详情页（L1 内二级页）：保留系统路由承载，不在本轮去路由范围
- 队列/历史多选态：返回先退多选再关面板（现状语义保留于新链）
- 大会员状态过期：以本地缓存的有效性字段为准显示，不做实时校验（现状账号信息展示同范式）

## Requirements

### Functional Requirements

- **FR-001**: 设置页与日志页 MUST 以层级条件渲染承载（退出系统路由），层序为：导航+胶囊之下、播放浮层之上/同段（日志层在设置层之上、播放浮层之下）
- **FR-002**: 高层 MUST 物理覆盖低层；设置层滑入/滑出过程 MUST 覆盖/揭示胶囊；系统 MUST NOT 保留任何胶囊显隐时序机制（在台标志、退场延时、显隐动画、可见性全局键）
- **FR-003**: 队列面板 MUST 收敛为单一挂载点且层序最高（L4），两入口行为与现状一致
- **FR-004**: 系统返回键 MUST 按层自上而下逐层关闭：队列（多选优先）→ 播放层内附属面板 → 播放层 → 日志层 → 设置层内附属面板（音质/历史，历史多选优先）→ 设置层 → 下层默认行为
- **FR-005**: 既有行为零回归红线：历史点播（浮层盖设置层）、bindSheet 附属返回拦截等既有行为 MUST 与现状一致；除三项批准变更（FR-009/FR-010/FR-011）外，全部用户可感知行为（入口/转场方向/返回语义/层内功能/空态表现）MUST 零变化
- **FR-006**: 三处滚动页底部避让 padding MUST 静态化并删除胶囊可见性全局键，取值与现状恒真分支一致；日志条数缓存（成员/加载/刷新）MUST 一并删除
- **FR-007**: 订阅源详情页 MUST 保留系统路由承载
- **FR-008**: 设置层/日志层转场 MUST 沿用树内条件渲染 + TransitionEffect 机制（播放浮层同范式，已在真机验证可行），滑入方向自右侧（对齐原导航 push 手感）
- **FR-009**: 音质面板在当前内容无多音轨（未登录兜底流）时 MUST 显示「64K」档位并附登录引导文案；有多音轨时 MUST 展示实际音轨列表（现状）
- **FR-010**: 设置页账号栏在登录且大会员状态有效时 MUST 显示大会员标识（贴近 B 站官方视觉），其余状态不显示
- **FR-011**: 播放历史面板标题、历史入口行、日志入口行 MUST NOT 显示条数计数

### Key Entities

- **层序契约（L1–L4）**：见 Layer Model，本轮核心不变量，后续迭代不得破坏
- **新增瞬态 UI 键**：设置层可见、日志层可见（AppStorageV2，BoolState 包装）
- **新增组件参数/资源**：SettingsRow 大会员徽标参数；徽标色资源
- **退役瞬态键/常量/成员**：设置页在台标志、胶囊可见性标志、导航退场定值延时、胶囊显隐动画时长、日志条数缓存
- **保留不变**：队列开合标志、历史面板标志（设置页树内承载不变）、播放层下滑手势的队列在台判定、清空队列双标志同收语义

## Success Criteria

- **SC-001**: 退出设置页场景胶囊随层滑出逐帧揭示，全程无延时突现（原 bug 根因消除，非症状修补）
- **SC-002**: 除三项批准变更外，全部用户可感知行为与重构前一致（入口/转场方向/返回语义/层内功能/空态表现）
- **SC-003**: 净删除 ≥ 5 项全局机制（两瞬态键、两常量、三段定时器逻辑、显隐 Monitor、日志计数缓存），新增仅两个层可见键与 SettingsRow 一个参数
- **SC-004**: 三项批准变更按 US5/US7/US8 验收标准落地
- **SC-005**: 构建通过；模拟器 UI 实测（层转场、返回链分层、队列盖浮层、历史点播覆盖序、深栈逐层关闭、静态 padding、三项批准变更）于验证阶段执行，模拟器用完关闭
